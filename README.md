# 死亡细胞模组管理器 · 更新分发目录

这个仓库**只放两样东西**：

| 文件 | 用途 |
|---|---|
| `version.json` | App 启动时读它，比对版本号，决定要不要提示"发现新版本" |
| `deadcells-mod-manager.apk` | 最新版的安装包（App 里的"去下载"就是这个直链） |

**这里没有任何源代码。** 仓库公开 ≠ 项目开源：GitHub 的公开仓库只表示"文件可以被匿名下载"，
别人看不见你本地的工程，也拿不到源码——除非你把源码推上来。

## 为什么不用买服务器

更新检查就一次 HTTP GET，读 300 字节的 json。GitHub 的 raw 文件本身就是免费 CDN，
不需要域名、不需要备案、不需要后台。发新版本只要改 json 里的两个数字 + 换一个 APK。

## 发新版本怎么做

在 `D:\Mod 管理器\update-repo` 里跑：

```powershell
.\发布新版本.ps1 -RepoUrl https://github.com/你的用户名/仓库名.git
```

脚本会自动：把 dist 里最新的 APK 复制过来、读它的版本号写进 version.json、提交并推送。

## 绝对不能放进这个仓库的东西

- `keystore.p12` / `*.jks` / `*.keystore`（签名私钥，泄漏等于别人能冒充你发版）
- 源码目录（`mobile/`、`engine/`、`app/`）
- `dist/对照-*.apk` 这种 1.7GB 的测试包
- 玩家日志里可能带的个人信息
